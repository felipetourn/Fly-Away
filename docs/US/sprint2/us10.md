## Qué se hizo

Cada compra confirmada recibe un número de factura único guardado en `pagos.numero_factura`. El backend genera un comprobante PDF con los datos del pago, reserva, vuelo, pasajeros, medio de pago, fecha e importe total y lo envía adjunto a la dirección de contacto de la reserva. El correo incluye versiones HTML y texto.

La confirmación y el descuento de asientos se guardan primero. El envío se ejecuta después del commit, por la API HTTP de Brevo (Render free bloquea el SMTP), por lo que una falla del envío o del armado del PDF se registra en el backend sin deshacer la compra ni repetir su confirmación. Los pagos rechazados no reciben número de factura ni disparan un email.

## Criterios de aceptación

| Criterio | ¿Cumple? | Evidencia |
| -------- | -------- | -------- |
| La factura se genera únicamente para compras confirmadas | ✅ | El número se asigna dentro de `confirmar_compra` solo al aprobar el pago; la generación/envío valida el estado `aprobado`. |
| El comprobante queda asociado a la operación correspondiente | ✅ | `Pago.numero_factura` identifica unívocamente el comprobante del pago. |
| Se utiliza la dirección de correo asociada al pasajero | ✅ | Se usa `Reserva.contacto_email`, con fallback al email de cuenta; test con email de contacto específico. |
| El pasajero recibe el email con el comprobante correspondiente | ✅ | Se envían HTML/texto y PDF adjunto con número de factura, vuelo, pasajeros, fecha, medio e importe. Prueba con backend local `locmem`. |
| No se envía una factura por una transacción rechazada | ✅ | El rechazo no asigna `numero_factura` ni registra callback; `test_pago_rechazado_no_genera_factura_ni_envia_correo`. |
| Un error de envío no debe provocar que se duplique la compra | ✅ | Envío posterior al commit y confirmación idempotente; `test_error_de_correo_no_revierte_ni_duplica_la_compra`. |

## Configuración

Sin `BREVO_API_KEY`, los mails se imprimen en la consola. Para enviar, configurar `BREVO_API_KEY` y `DEFAULT_FROM_EMAIL` (remitente verificado en Brevo) como indica [arquitectura.md](../../arquitectura.md#emails). No guardar credenciales en el repositorio.
