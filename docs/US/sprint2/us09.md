## Qué se hizo

Cada pasaje confirmado cuenta con un ticket individual identificado por su `codigo_pasaje`. El pasajero puede abrir el detalle visual del ticket desde sus reservas y descargarlo como PDF. El ticket incluye los datos del viajero, vuelo, fechas y horarios de salida y llegada, origen, destino, clase, asiento y código.

El ticket y su PDF solo están disponibles cuando la reserva está pagada y únicamente para el pasajero que realizó la compra. El PDF se genera bajo demanda y se descarga como archivo adjunto. Las reservas pendientes y los pagos rechazados no habilitan el detalle ni la descarga.

## Criterios de aceptación

| Criterio | ¿Cumple? | Evidencia |
| -------- | -------- | -------- |
| El ticket solamente se genera cuando la compra fue confirmada correctamente | ✅ | El detalle y el PDF validan `reserva.estado = pagada`. `test_ticket_no_se_genera_si_compra_no_confirmada`. |
| No se genera un ticket ante una operación de pago rechazada | ✅ | El rechazo mantiene la reserva pendiente y no habilita el PDF. `test_ticket_no_se_genera_ante_pago_rechazado`. |
| Cada ticket queda asociado a la compra correspondiente | ✅ | Cada `Pasaje` pertenece a una reserva mediante `Pasaje.reserva`. |
| Cada ticket queda asociado al pasajero correspondiente | ✅ | Cada `Pasaje` conserva nombre, apellido y DNI del viajero; el detalle está protegido para el comprador propietario de la reserva. |
| Cada ticket puede ser identificado individualmente | ✅ | `codigo_pasaje` es único y aparece en el detalle y el nombre del PDF. `test_cada_ticket_se_identifica_individualmente`. |
| Incluye pasajero, vuelo, fecha, horario, origen, destino y clase | ✅ | Detalle JSON y PDF; pruebas `test_visualizar_ticket_detalle_json` y `test_ticket_se_genera_y_descarga_tras_pago_aprobado`. |
| El pasajero puede visualizar el ticket generado | ✅ | Enlace por pasaje desde `/reservas` y página `/pasajes/:codigo`. |
| El pasajero puede descargar el ticket electrónico | ✅ | Descarga autenticada de `/api/pasajes/{codigo}/pdf/` como archivo PDF adjunto. |
